# FUTURE_ML_01 - Sales Forecasting for Retail Business

## 📌 Task 1 Overview

This is Task 1 of my Machine Learning Internship at Future Interns. In this project, I built a sales forecasting model for a retail business using daily sales data.

### 🎯 Objective
Predict future sales trends using Time Series Forecasting and analyze patterns like seasonality and growth.

- Matplotlib

- Regression analysis
- Data visualization
